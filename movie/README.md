This movie app is built with React, featuring a mobile-first responsive design and a modular UI with reusable components like MovieCard, SearchBar, and MovieDetails. It uses React Router to navigate between Home, Movie Details, and Favorites pages, while global state management is handled with the React Context API. The app includes a trending movies section that dynamically displays popular movies from a public API. For an enhanced user experience, it also supports light and dark mode toggling.
